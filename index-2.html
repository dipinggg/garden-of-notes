One small thing first 🌱

The garden isn't connected to its soil yet, so nothing will save. Open index.html, find DB_URL near the top of the script, and paste your Firebase Realtime Database URL there.

  1. Go to console.firebase.google.com and create a free project.
  2. In the left menu: Build → Realtime Database → Create Database. Pick Start in test mode.
  3. Copy the URL at the top — it looks like https://something-default-rtdb.firebaseio.com.
  4. Paste it into DB_URL, save, and push the file again.
